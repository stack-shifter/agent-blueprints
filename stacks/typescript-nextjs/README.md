# typescript-nextjs

Vault-internal notes. Not copied into projects — only `agent.md` is.

## Pick this when

The project is a Next.js app using the App Router.

## Assumes

- App Router, not Pages Router
- Server Components as the default
- pnpm

## Pick a sibling instead when

- **`typescript-node`** — a service, CLI, or library with no framework. If the project
  only happens to include a small web surface, that baseline is the better fit.
